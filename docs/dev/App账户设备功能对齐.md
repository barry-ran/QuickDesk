# App 账户与设备功能对齐

基线：账户列表 PR #36 已合并后的 `dev` / `419d70342112413de34659d4ccbd6a55af436990`。本次仅扩展产品层，不修改服务端账户、归属、权限或 Remoting 协议。

## 源码依据与范围

- Qt：`QuickDesk/src/manager/AuthManager.cpp`、`CloudDeviceManager.cpp`、`QuickDesk/qml/quickdeskcomponent/LoginDialog.qml`、`QuickDesk/qml/pages/DeviceListPage.qml`。
- 服务端：`SignalingServer/docs/user-api-docs.md` 以及对应 handler；接口文档不是新增语义授权。
- 原 App：`quickdesk-android/lib/controller/home_page.dart` 只有主控/被控；`api/signaling_api.dart` 只提供访问码校验和 ICE；账户层缺失。
- Web：`WebClient/src/views/DevicesPage.vue`、`RecordingsPage.vue`、`ResetPasswordPage.vue`。

## 其他尚未对齐的相邻能力

1. **Host 账户关联已补齐**：绑定必须明确确认，登录/恢复/重连均不自动转移所有权；尚无自动绑定偏好。
2. **资料修改与活跃会话管理**：仍未扩展；密码重置使用既有 WebClient 页面。浏览器内改密由既有网页负责，不把网页成功误报为 App 已重新登录。
3. **录像索引/播放入口**：Web 已有 `RecordingsPage.vue`；App 没有。索引 API 不等于移动端已具备录像引擎。
4. **可信设备/审批策略**：Qt 设置有 trust confirm mode，App 现有 `SignalingApi` 仅访问码换票；不在本次引入持久信任或默认同意。
5. **多显示器/虚拟屏/隐私屏等高级远控选项**：Qt 已有产品入口，App 远控工具条尚未覆盖。与本次账户层无关，不改 Remoting。
6. **已有功能不重复重写**：App 已有剪贴板、文件传输、主控/被控、移动触控交互；保留原连接历史与全部已合并移动控制逻辑。

## 三端排序契约

- 我的设备：`online == true` 优先，其后按显示名称（非空 `remark` → `device_name` → `device_id`）自然排序，最后设备 ID 确定顺序。
- 我的收藏：名称自然排序，再按设备 ID。后端收藏行没有共同的在线/最近连接字段，不虚构状态。
- ASCII 大小写不敏感；数字片段自然比较（2 在 10 前）；非 ASCII 使用确定性 UTF-16 顺序，不依赖系统语言/区域。具体空白、前导零、同名行为以共享夹具为准。
- 不使用 `last_seen_at` 冒充最近连接时间，不使用当前时钟参与排序；输入数据不变则刷新不抖动。
- 排序只作用于展示副本，不改变实时状态的原始顺序/修订号、不写回服务端。

## 安全与验收边界

- 测试只用 mock/fixture；不创建真实账户、不发真实验证码、不建立真实设备归属或信任授权。
- 令牌不写日志、不写 SharedPreferences、不跨服务器重用；不放宽 TLS 校验。对沿用的明文服务器配置显示风险提示。
- 本地 Flutter bootstrap 和浏览器运行受环境限制，不能把代码审阅/格式化宣称为真机验证。最终 lint/test/APK 构建以 PR 指定 SHA 的 CI 为准。
- Android 真机需另验安全存储、输入法/大字/横屏、网络切换、后台恢复、扫码/Host 互通。CI 通过不替代这些检查。


## 绑定、历史与重置的安全闭环（本次）

- `HostCredentialStore` v2 以规范化 HTTP/WS 服务器地址与 API key 的摘要分区 UUID、设备 ID、访问码与安全存储 secret。旧全局凭据没有可信来源，**不迁移、不发送到任何服务器**；升级后首次开启被控会生成新本机 ID，旧设备记录需用户自行核实后解绑。
- Host 启动后可在账户页点「绑定本机到当前账户」。确认框标明本机 ID、账户、服务器与归属转移；确认后复核账户 epoch、服务器页面代次和设备身份。重复点击、取消及迟到结果均不能静默转移归属。
- 登录/账户恢复仅恢复账户；不会自动绑定。显式退出使用当前服务器的已 provision 本机 ID 清设备 session，再撤销账户 session；不解绑设备、不中止已授权被控。Host Keystore 读取失败也不阻止账户退出，但提示设备 session 撤销未确认。服务端撤销失败不能宣称远端 `logged_in` 已清除。
- 保存新服务器/API key 后停止旧 Host 并重新加载隔离凭据。停止会等待正在进行的启动步骤返回后释放采集/会话（系统采集授权对话框和底层 WebSocket 握手未返回时可能延迟，不绕过系统授权）；迟到 provision 只保存原服务器的一次性 secret，不继续采集、监听或绑定。
- 云记录只在该账户对应服务器的主控连接验证开始时捕获账户实例与 epoch。手动连接和云设备/收藏连接均记录终态；失败原因只发送固定安全代码，绝不包含访问码、令牌、原始异常、SDP 或设备名称。账户退出/切换、服务器实例销毁后不将旧尝试归入新账户。
- **幂等边界**：每次尝试本地只提交一次终态。现有后端 `POST /v1/me/connections` 不提供幂等键，因此超时、网络失败、5xx 不自动重放；仅原有账户层对明确拒绝的 401 刷新并重试一次。离线、进程退出或不确定提交结果可能丢记录，无持久秘密队列、不承诺 exactly-once。云设备访问码查询/输入对话框发生在连接尝试之前，不生成连接记录。REST 明确的 TimeoutException 记录为 timeout；会话状态机仅提供 failed 时记录为 failed，不从原始错误文字猜测超时。
- 忘记密码的 URL 仅来自同服务器 preset；只允许 http(s)、无用户名/密码、无原查询串或 fragment，再附加 Qt 相同 hash 路由。外部跳转前显示完整地址和 HTTP 风险，未配置/不安全地址报错，不调用虚构密码接口，不附加账户凭据。

新增 mock 单元/Widget 回归覆盖凭据分区与旧键拒绝、Keystore 故障、确认取消与账户/服务器/设备变化、退出不中断、启动中停止与迟到注册、连接终态去重/隐私/账户隔离、preset URL 校验与迟到跳转取消。Flutter analyze、完整测试和 APK 构建以最终 PR SHA 的 CI 为准；真机权限授权、Keystore、浏览器返回与 Qt/Android 互通仍需实际设备验收。
